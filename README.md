## ✨ Возможности

- **6 типов СМО** на выбор из меню
- **Гибкий ввод данных** — программа ничего не додумывает за пользователя:
  - входящий поток: интенсивность **λ** *или* среднее время между заявками **t_пр**;
  - обслуживание: интенсивность **μ** *или* время обслуживания **t_обс**;
  - единицы измерения на выбор: в час / в минуту / в секунду (для времени — часы / минуты / секунды);
  - дробные числа можно вводить и через точку, и через запятую.
- **Проверка ввода** и понятные сообщения об ошибках, в том числе о нарушении условия стационарности (ρ < 1 и ρ/n < 1 для систем с неограниченной очередью).
- **Выгрузка в настоящий `.xlsx`** (не CSV): исходные данные, приведённые параметры и результаты оформлены таблицами, значения записаны числами. Устанавливать Excel для создания файла не нужно.

## 🧮 Поддерживаемые типы СМО и показатели

| Тип СМО | Рассчитываемые показатели |
|---|---|
| Одноканальная с отказами | P₀, Pотк, Q, A |
| Многоканальная с отказами | P₀, Pотк, Q, A, k̄ |
| Одноканальная с неограниченной очередью | P₀, Lоч, Tоч, Lсист, Tсист |
| Многоканальная с неограниченной очередью | P₀, Lоч, Tоч, Lсист, Tсист |
| Одноканальная с ограниченной очередью | P₀, Pотк, Q, A, Lоч, Tоч, Lсист, Tсист |
| Многоканальная с ограниченной очередью | P₀, Pотк, Q, A, k̄, Lоч, Tоч, Lсист, Tсист |

**Обозначения**

| Символ | Смысл |
|---|---|
| λ, μ | интенсивность потока заявок / обслуживания (в расчёте приводятся к «в час») |
| ρ = λ/μ | приведённая интенсивность потока |
| n, m | число каналов / максимальная длина очереди |
| P₀ | вероятность простоя (все каналы свободны) |
| Pотк | вероятность отказа |
| Q, A | относительная и абсолютная пропускная способность |
| k̄ | среднее число занятых каналов |
| Lоч, Tоч | среднее число заявок в очереди / среднее время ожидания в очереди |
| Lсист, Tсист | среднее число заявок в системе / среднее время пребывания в системе |

> Для систем с ограниченной очередью времена вычисляются как `Tоч = Lоч / λ`, `Tсист = Lсист / λ`.

## 🚀 Запуск

### Требования

- Windows 10 / 11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Visual Studio 2022 (рабочая нагрузка «Разработка классических приложений .NET») — по желанию

### Через Visual Studio

1. Откройте `WpfApp1.sln`.
2. Дождитесь восстановления NuGet-пакетов (подтянется [ClosedXML](https://github.com/ClosedXML/ClosedXML)).
3. Нажмите **F5**.

### Через командную строку

```bash
git clone <адрес-репозитория>
cd WpfApp1/WpfApp1
dotnet run
```

## 🖥️ Как пользоваться

1. Выберите **тип СМО**. Поля `n` и `m` появятся только там, где они нужны.
2. Задайте **входящий поток**: выберите способ (λ или t_пр), введите значение и единицу измерения.
3. Задайте **обслуживание**: выберите способ (μ или t_обс), введите значение и единицу измерения.
4. Нажмите **«Рассчитать»** — результаты появятся справа.
5. Нажмите **«Выгрузить в Excel»**, чтобы сохранить отчёт в `.xlsx`.

### Пример

Многоканальная СМО с отказами: `n = 3`, `λ = 4 в час`, `t_обс = 30 мин` (то есть μ = 2 в час, ρ = 2).

```text
Тип СМО: Многоканальная с отказами
Приведённые параметры:
λ = 4,0000 заявок/час; μ = 2,0000 обсл./час; ρ = 2,0000
------------------------------------------------------------
Вероятность простоя (P0): 0,1579
Вероятность отказа (Pотк): 0,2105 (21,05%)
Относительная пропускная способность (Q): 0,7895
Абсолютная пропускная способность (A): 3,16 заявок/час
Среднее число занятых каналов (k): 1,5789
```
